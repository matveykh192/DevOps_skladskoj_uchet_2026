## Методика

Знаменатель для формального учёта — **13 самостоятельных функциональных пунктов раздела 3.6 ТЗ**. Считаем **«покрыто»**, только если автоматический тест проверяет существенную ожидаемую операцию данного пункта, а не просто наличие класса, схемы или доступность смежного API. **«Частично» не засчитываем как выполненный пункт**. Статус `не проверено` не означает автоматически, что сама функция в приложении отсутствует.

## Проверяемые обязательные правила раздела 2.4

| Правило | Имеющееся доказательство | Статус |
|---|---|---|
| 1. Доступ только после аутентификации | Только тесты хеша и JWT | Частично |
| 2. Операции соответствуют роли | Нет ролевых HTTP-тестов | Не проверено |
| 3. Материал и единица существуют до позиции поступления | `test_postgresql_relationships_are_persisted`, проверка неверного unit ID | Частично |
| 4. Поставщик существует до поступления | Проверяется связь с созданным поставщиком | Частично |
| 5. Каждая позиция связана с поступлением и материалом | `test_postgresql_relationships_are_persisted` | Покрыто |
| 6. Количество положительное | `test_receipt_rejects_nonpositive_quantity`, `test_receipt_negative_quantity_rejected` | Покрыто |
| 7. Цена неотрицательная | `test_receipt_rejects_negative_price`, `test_receipt_accepts_zero_price` | Покрыто на уровне схемы |
| 8. Поступление содержит несколько позиций | Нет целевого теста | Не проверено |
| 9. Материал может находиться в разных поступлениях | Нет целевого теста | Не проверено |
| 10. Нет дубля материала в одном поступлении | Нет целевого теста (дубликат **номера поступления** — другое правило) | Не проверено |
| 11. Корректная дата | Нет целевого теста | Не проверено |
| 12. Номер документа обязателен | `test_document_number_is_required` | Покрыто на уровне схемы |
| 13. Стоимость позиции = количество × цена | Проверка одного итогового значения `125.0` | Частично |
| 14. Итоговая стоимость = сумма позиций | Только одна позиция, сумма нескольких не проверена | Не проверено |
| 15. Изменения/удаления не нарушают связи | `test_cannot_delete_material_with_receipt_history`, `test_receipt_deletion_reverses_balance`, `test_postgresql_relationships_are_persisted` | Частично |
