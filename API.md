# Описание API

Базовый URL: **http://localhost:8000**

Интерактивная документация (Swagger UI): **http://localhost:8000/docs**  
Альтернативная (ReDoc): **http://localhost:8000/redoc**

---

## Аутентификация

Проект использует **JWT** (Bearer-токены).  
Формат передачи: HTTP-заголовок `Authorization: Bearer <token>`.

### POST /auth/login

Получить JWT-токен.

**Формат запроса:** `application/x-www-form-urlencoded`

| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `username` | string | да | Логин пользователя |
| `password` | string | да | Пароль |

**Пример:**

```bash
curl -X POST http://localhost:8000/auth/login \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=admin&password=admin123"
Ответ 200:

json
{
  "access_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
  "token_type": "bearer"
}
Ответ 401:

json
{ "detail": "неверный логин или пароль" }
Токен живёт 24 часа. При истечении — 401 Unauthorized, клиент должен перелогиниться.

Система
GET /health

Ответ 200 (всё работает):

json
{
  "status": "healthy",

Материалы
GET /materials/
Список всех активных материалов с текущими остатками.

Требуется авторизация: нет.

Ответ 200:

json
[
  {
    "id": 1,
    "name": "Болт М-8",
    "measurement_unit_id": 1,
    "description": "Стальной болт",
    "is_active": true,
    "quantity": 100.0
  }
]
GET /materials/low-stock?threshold=10
Материалы с остатком ниже заданного порога. Полезно для понимания, что пора заказывать.

Требуется авторизация: нет.

Параметры запроса:

Параметр	Тип	По умолчанию	Описание
threshold	float	10.0	Порог остатка
Ответ 200:

json
{
  "threshold": 10.0,
  "count": 2,
  "items": [
    {
      "id": 3,
      "name": "Шайба 8",
      "measurement_unit_id": 1,
      "description": "Плоская шайба",
      "quantity": 0.0
    },
    {
      "id": 5,
      "name": "Болт М-10",
      "measurement_unit_id": 1,
      "description": "Болт с шестигранной головкой",
      "quantity": 5.0
    }
  ]
}
Пример запроса:

bash
curl "http://localhost:8000/materials/low-stock?threshold=10"
GET /materials/{id}
Один материал по ID.

Ответ 200: объект материала.
Ответ 404: { "detail": "материал не найден" }.

POST /materials/
Создать новый материал.

Требуется авторизация: да.

Тело запроса (JSON):

json
{
  "name": "Болт М-10",
  "measurement_unit_id": 1,
  "description": "Болт с шестигранной головкой"
}
Ответ 201: созданный объект с id, quantity = 0, is_active = true.
Ответ 400: если материал с таким названием уже есть.

PUT /materials/{id}
Обновить материал (название, единицу измерения, описание).

Требуется авторизация: да.

Тело запроса (JSON, все поля опциональны):

json
{
  "name": "Болт М-10 (обновлённый)",
  "description": "Новое описание"
}
Ответ 200: обновлённый объект.

DELETE /materials/{id}
Удалить материал жёстко.

Требуется авторизация: да.

Ограничение: нельзя удалить материал, по которому есть движения (поступления или расходы).
Если есть — 400 с текстом:

json
{
  "detail": "Нельзя удалить материал, у которого есть история движений. Сначала удалите связанные документы."
}
Ответ 200: { "message": "Материал удалён" }.

Поступления (Приход)
GET /receipts/
Список всех поступлений с составом и суммой.

Ответ 200:

json
[
  {
    "id": 1,
    "receipt_number": "П-001",
    "supplier_id": 1,
    "receipt_date": "2026-09-25",
    "status": "registered",
    "total_amount": 850.00,
    "items": [
      {
        "id": 1,
        "material_id": 1,
        "material_name": "Болт М-8",
        "quantity": 100.0,
        "unit_price": 5.00,
        "line_total": 500.00
      },
      {
        "id": 2,
        "material_id": 2,
        "material_name": "Гайка М-8",
        "quantity": 100.0,
        "unit_price": 3.50,
        "line_total": 350.00
      }
    ]
  }
]
POST /receipts/
Создать поступление. Требуется авторизация.

При создании:

если материала с таким названием нет — он создаётся автоматически;

если поставщика с таким названием нет — он создаётся автоматически;

остаток материала на складе увеличивается на количество из позиции.

Тело запроса:

json
{
  "receipt_number": "П-002",
  "receipt_date": "2026-09-25",
  "supplier_name": "ООО МеталлСнаб",
  "items": [
    {
      "material_name": "Болт М-10",
      "measurement_unit_id": 1,
      "quantity": 50,
      "unit_price": 8.00
    }
  ]
}
Ответ 201: { "message": "Поступление оформлено", "id": 2 }.
Ответ 400: если номер документа уже существует или позиций нет.

DELETE /receipts/{id}
Удалить накладную. Требуется авторизация.

При удалении:

остатки материалов уменьшаются на позиции этой накладной;

позиции удаляются каскадно.

Ответ 200: { "message": "Поступление удалено" }.

Расход (Выдача)
GET /issues/
Список расходных накладных.

Ответ 200:

json
[
  {
    "id": 1,
    "issue_number": "Р-001",
    "department": "Цех №1",
    "issue_date": "2026-09-25",
    "status": "registered",
    "items": [
      {
        "id": 1,
        "material_id": 1,
        "material_name": "Болт М-8",
        "quantity": 30.0
      }
    ]
  }
]
POST /issues/
Создать расход. Требуется авторизация.

При создании:

проверяется, что материала хватает на складе;

если не хватает — 400 с указанием доступного количества;

остаток материала уменьшается.

Тело запроса:

json
{
  "issue_number": "Р-002",
  "department": "Цех №2",
  "issue_date": "2026-09-25",
  "items": [
    { "material_id": 1, "quantity": 20 }
  ]
}
Ответ 201: { "message": "Расход оформлен", "id": 2 }.
Ответ 400: { "detail": "Недостаточно материала «Болт М-8». Остаток: 50, запрошено: 80" }.

DELETE /issues/{id}
Удалить расход. Требуется авторизация.

При удалении:

материалы возвращаются на склад (остаток увеличивается обратно).

Ответ 200: { "message": "Расход удалён" }.

Ошибки
Единый формат ответа при любой ошибке:

json
{ "detail": "текст ошибки" }
Ошибки валидации (422) содержат дополнительный массив:

json
{
  "detail": "Ошибка валидации данных: body.name: Field required",
  "errors": [ ... ]
}
Код	Значение
200	Успех
201	Создано
400	Некорректный запрос (например, дубликат, недостаток остатка)
401	Не авторизован / токен истёк
404	Не найдено
422	Ошибка валидации данных
500	Внутренняя ошибка сервера
503	Сервис недоступен (БД не подключена)
